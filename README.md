# TWIRVALL — Documentos legais

Política de privacidade, termos de utilização e página do convite da aplicação
TWIRVALL, publicados por GitHub Pages em
**https://twirvall.com**.

A fonte destes ficheiros vive no repositório da app, em `docs/legal/`. Este
repositório existe apenas para os tornar públicos sem expor o código.

**Ao alterar:** actualizar primeiro em `docs/legal/` no repositório da app,
depois copiar para aqui — senão os dois divergem.

Os documentos legais existem em português (Portugal) e inglês (todos os outros
países). Não se traduzem para outras línguas — ver a decisão 7 do plano
TWIRVALL.

O repositório antigo, `rideatlas-legal`, fica no ar com redirects para aqui:
as versões antigas da app e os QR codes impressos do convite apontam para lá.

`CNAME` liga o domínio; `.nojekyll` desliga o processamento Jekyll, que aqui
não serve para nada.
